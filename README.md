# 王垠百科

[访问网站](https://yinwang-wiki.github.io/site/) · [提交资料修正](https://github.com/yinwang-wiki/site/issues/new)

本仓库是王垠百科网站的源代码与资料索引，收录公开账号、开源项目、论文、采访和历史网站存档。

> [!IMPORTANT]
> 这是社区维护的非官方网站，并非王垠本人维护，也不代表王垠本人的立场。

## 仓库结构

- `index.md`：网站首页与资料索引
- `_posts/`：站内文章
- `wiki/`：专题资料
- `assets/`：样式、图片与归档文件
- `_layouts/`、`_includes/`：Jekyll 页面模板

## 参与维护

欢迎补充公开、可核验的来源，修复失效链接或纠正事实错误。提交前请阅读 [CONTRIBUTING.md](CONTRIBUTING.md)。
